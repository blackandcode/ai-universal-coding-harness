# Configuration

AI Universal Coding Harness uses layered JSONC configuration.

## Precedence

From highest to lowest:

1. CLI arguments
2. `AI_HARNESS_*` environment variables
3. local project config: `<repo>/.ai-orchestrator/config.jsonc`
4. tracked project config: `<repo>/.ai-universal-coding-harness.jsonc`
5. legacy tracked config: `<repo>/.ai-stage-orchestrator.jsonc` (migration compatibility only)
6. global user config
7. built-in defaults

The local config is generated by `ai-harness init` and remains untracked. Use the tracked root config when a team intentionally wants to share defaults.

## Global config locations

```bash
ai-harness config paths
```

Typical locations:

- Linux: `~/.config/ai-universal-coding-harness/config.jsonc`
- macOS: `~/Library/Application Support/ai-universal-coding-harness/config.jsonc`
- Windows: `%APPDATA%\ai-universal-coding-harness\config.jsonc`

Set `AI_HARNESS_CONFIG_HOME` to override the global config directory.

## Create config

```bash
ai-harness config init --global
ai-harness config init --project
ai-harness config init --local
```

Use `--force` only when intentionally replacing an existing config file.

## Example

```jsonc
{
  "executorHarness": "cursor",
  "reviewerHarness": "codex",
  "permissionMode": "auto_safe",
  "qualityCommand": "npm run check",
  "branchPrefix": "ai-harness",
  "maxPlanReviews": 3,
  "finalPlanReview": true,
  "maxExecutionAttempts": 3,
  "harnessModules": [],
  "harnesses": {
    "cursor": {
      "binary": "agent",
      "model": "gemini-3.8-flash",
      "thinking": "high",
      "turnTimeoutMinutes": 45,
    },
    "codex": {
      "binary": "codex",
      "model": "gpt-6-astra",
      "reasoningEffort": "low",
      "verbosity": "low",
      "timeoutMinutes": 8,
      "contextMode": "evidence_only",
    },
  },
}
```

Legacy `AI_STAGE_*` environment variables remain accepted as a migration fallback, but new configuration should use `AI_HARNESS_*`.
